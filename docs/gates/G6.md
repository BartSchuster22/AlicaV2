# G6 — Authenticated local IPC

Status: **design review candidate; implementation and G6 exit qualification pending**.

G5 acceptance and IPC baseline approval are recorded in [G5-OWNER-ACCEPTANCE.md](G5-OWNER-ACCEPTANCE.md) and [G6-BASELINE-APPROVAL.md](G6-BASELINE-APPROVAL.md). They are not being reopened.

Review together:

- [ADR-013](../adr/ADR-013.md): native process authentication, launch/package binding, confinement, dependency-policy addition and cleanup.
- [IPC profile](../g6/IPC-PROFILE.md): directional frames, broker-only authority, deadlines, streams/events, queues and recovery limits.
- [Draft frame schemas](../g6/draft/frames.schema.json) and [structural examples](../g6/draft/examples.json).
- [Qualification matrix](../g6/QUALIFICATION.md): required runtime tests and explicit evidence gaps.
- [Design evidence](../../evidence/g6-design/): actual platform probes, schema checks and check-pipeline record.

The proposed profile uses native Linux peer credentials/pidfds plus Landlock/seccomp, not containers. It needs an approved native bridge and locked C toolchain. The initial equivalence profile has one active invocation per worker, bounded cyclic/reentrant rejection and no unsolicited background outbound calls; it must not be described as unrestricted inproc concurrency equivalence.

The recorded review-before-implementation gate remains in force. No IPC adapter, production native launcher, transport-equivalence report or complete hostile-process qualification is claimed by this candidate. The restricted Node probe is feasibility evidence only. Approval of the ADR, schemas, native-build addition and profile limits is required before implementation.
