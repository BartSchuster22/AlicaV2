R2 retains one stateful provider instance, permits bounded overlapping and successful reentrant calls, and binds scope/budget to receiver-owned endpoints rather than asserted parent IDs. It does not claim that a shared compromised process cannot use another legitimate capability it holds, nor that killing that process preserves sibling calls.

The review-before-implementation gate remains: approve this concrete protocol/ancillary-data design, limits, native build lock and explicitly stated threat boundary before native/adapter implementation. Schema/model/probe success is not transport-equivalence qualification. Earlier single-active evidence remains historical only.
