# M2 governed domain boundary

Target: HTTP adapter ─┐ / ACAP adapter ─┴→ GovernedMemoryDomain → Store Protocol → SqliteStore.
No adapter may invoke Store directly to bypass authorization, visibility, policy, lifecycle, idempotency, audit or retrieval evidence. Native startup/composition owns SQLite lifecycle; domain sees a port, not SQL/FTS/path/connection. Preserve source semantics rather than build CRUD replacement.

Observed existing boundary: main.py has top-level auth/invariant helpers and nested FastAPI route functions; middleware owns denial audit. Store protocol declares only create_record, create_record_idempotent, get_record, get_visible_record, list_records, search_records. Concrete SqliteStore exposes all mutation/graph/pages/findings/audit/usage/lifecycle methods and close. HTTP currently depends directly on SqliteStore. Hence extraction requires (1) pure domain errors/authority object, (2) route business bodies outside HTTP, (3) complete typed port for actual calls, (4) existing route adapters preserving response/status/header behavior, (5) denial audit shared correctly. Calling FastAPI endpoints internally or ASGI-loopback from ACAP is rejected.

Domain owns trusted-authority validation, permission/scope, record policy and lifecycle preconditions, idempotency/version/reason checks, request-hash semantics, domain errors, result models and denial audit. Store owns atomic mutation/idempotency/success audit, reference integrity, migration/recovery, query/pagination/FTS and read evidence persistence. HTTP owns bearer/delegation authentication, header/query parsing, error envelope and transport-level validation audit. ACAP owns public schema, trusted caller mapping, fixed Python operation framing, cancellation/deadline/error translation; maps no actor from input.

Private Python process-per-call bridge is a bounded candidate already demonstrated with neutral echo. Future memory children may open only explicit isolated operator paths, invoke domain once and close. No ambient production defaults, no generic route/method registry. HTTP and ACAP must instantiate the SAME domain code. Durable Store transactions allow explicit same-key replay after ambiguous crash; kill is not rollback guarantee. Normal service stop/restart persists store; per-call worker death does not imply service regrant or transparent retry. Implementation-dependent concurrency/timeout tests remain mandatory.

Portability belongs to restricted domain/operator authority and a transactional Store port, not arbitrary SQL exposed to consumer. Fresh empty target; no implicit canonical promotion, overwrite or scope remapping. Retained/excluded history and external bytes must be explicit (M5/M13–M15), not claimed equivalent by copying only record text.

Acceptance: HTTP suite regression, direct domain governance negatives, public ACAP create/get/search with stable ID/provenance and restart, forged authority rejection, denial audit/retrieval evidence, same governed behavior from both adapters, port no SQL leakage. M8/M9/M10/M11 remain unexecuted. These are reviewed source-derived design obligations; no product code has been changed to implement them yet.
