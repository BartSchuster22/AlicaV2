# M5 canonical portable memory model / format v1

Design, not executed portability qualification. Canonical means deterministic provider-independent exchange, NOT the record role canonical. ACAP capability model, portable domain model, SQLite storage model and backup format remain distinct.

Envelope: format='alica.governed-memory/v1', modelVersion=1, payload={entities,records,relations,artifacts,findings,auditEvents,retrievalEvents}, integrity={algorithm:'sha256',digest:<payload bytes digest>}. Only exact known keys/format/modelVersion/algorithm accepted. Source provider/schema/version and exporter build identity may be provenance in a separate manifest, not necessary to decode payload. No SQLite pages, row layouts, FTS tables or SQL in interchange. Arrays are explicit even when empty. Publish JSON Schema/field descriptions and non-production fixture.

Objects use existing semantic field names as defined in source schemas, not SQL columns ending _json. Entities retain composite identity; records retain rec_UUID, title/content, role/lifecycle/write_policy, scope, linked entity, topic/tags/confidence, provenance/source_refs/attrs, author, versions, timestamps, supersession links, previous_lifecycle/lifecycle_changed_at/deleted_at. Relations retain typed endpoints and versions; artifacts retain links/URI/type/checksum/metadata/provenance, never external bytes. Findings retain subject/state/resolution/reviewer/history timestamps and versions. Audit/retrieval events retain recorded actor, action/query, scope/detail/count/degraded and chronology/identifiers; imported assertions are not independently authenticated historical facts. Existing source has no separate full mutation-history table: superseded snapshots, links and audit are the available history; do not invent missing old patch text.

Determinism: one Store read transaction supplies all seven collections from a consistent snapshot; semantic object keys sorted lexically by Unicode code point, compact JSON with ASCII escapes, finite JSON numbers only, UTF-8, no insignificant whitespace. Collections sorted by composite type/id for entities, stable id for domain objects and numeric source event id for events. Preserve list order inside content metadata. Export's optional wall-clock/capture-path/process/build diagnostics are outside hashed payload and excluded from semantic equality. Existing semantic timestamps/version/author are preserved, not zeroed as volatile. A repeated export without domain changes has identical bytes/hash. Concurrent writes may appear entirely before/after snapshot, never mixed tables. Streaming pagination across independent HTTP reads is NOT a consistent export.

Authorization: export restricted to operator-owned whole isolated domain with explicit audit/review/archive access and data-root permission; not worker ACAP access. v1 does not support filtered partial graph exports; deny partial authority rather than leak ancestors/unrelated roots. Import requires an explicit operator-only ImportAuthority (not deserialized from envelope), authorized target/root(s), expected digest supplied out of band, restore-state permission, and explicit canonical-preservation authorization for any canonical records. Ordinary create-working, read/search or public create capability cannot import/promote. No role defaults, automatic canonical promotion, actor substitution or scope remapping. Historical imported actors are asserted provenance, while importer identity is separately audited.

Fresh-target rule: only a new initialized empty isolated store is supported, including empty domain/audit/retrieval/idempotency state. Reject any ID conflicts, duplicate identities, nonempty target or attempted merge/upsert. Prevalidate full format/checksum, finite values/size/count bounds, models, all references, sibling scope restrictions, role/lifecycle/deletion/policy/supersession consistency and applicable authority BEFORE inserting; repeat target-empty check under exclusive transactional mutation lock. For interrupted import, one transaction commits entire graph or rolls back; persist no partial successful state. Application failure after commit is ambiguous: operator inspects explicit import receipt/target digest, never blindly retries or clears target. Import receipt belongs to local import provenance, outside exported source semantic collections; source audit chronology unchanged. Tests must prove this, not assume SQLite guarantees alone.

Integrity vs authenticity: SHA256 detects corruption relative to a trusted expected digest. An envelope's own digest cannot authenticate who authored it or authorize canonical truth. Transport/operator verifies source custody out of band; no new PKI or signature claims. Tampered checksum, self-consistent untrusted payload without authority, unknown versions/fields/algorithms, broken references, duplicate IDs, invalid lifecycle, missing canonical authorization and interrupted import are mandatory negatives. Bounds must be explicit in implementation/format schema, not silent truncation.

M13–M15 proof: export isolated fixture with all supported collections and nontrivial roles/policies/history/relationships; import fresh empty store; re-export source-equivalent payload, IDs/counts/metadata/scopes/policies/history/reference checks; behaviorally demonstrate imported working actor still cannot promote/edit outside authority. Import-generated provenance receipt excluded from source-state semantic comparison explicitly. Derived indexes rebuilt; external artifact bytes not fetched. No claim of universal DB backup restore or production adoption.
