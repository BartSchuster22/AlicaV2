# M2 governance responsibility mapping

Sources read: B docs ADR-0001-TIER3-BOUNDARY, CONTRACT_V1, GOVERNANCE, ARCHITECTURE, API, UNIFY_ADAPTER; app/main.py in full, Store protocol/source method inventory; frozen ACAP public types/SDK and Foundation native Host attachment. This is design mapping, not runtime preservation proof.

| Responsibility/current owner | Enforcement / contract | Frozen ALICA equivalent and mapping | Gap / bypass risk / Phase5.1 action |
|---|---|---|---|
| Authentication, permission mapping, actor propagation: UNIFY | bearer grant + authorized X-MemoryV4-Actor in main.require_auth; ADR/Contract v1 | Host grants admit operations; OperationContext.caller principal/instance/scope is trusted | No automatic UNIFY human identity equivalence. ACAP operator-owned explicit mapping narrows trusted caller to actor/root/permissions; reject absent mapping and body authority. Preserve UNIFY production path unchanged. |
| Scope and visibility: MemoryV4 | _authorize_effective_scope, ScopePath, get_visible/page/search/context | Host scope controls capability visibility, NOT memory data scope | Explicit data-root mapping, reuse descendant mutation / ancestor-or-equal read logic; siblings hidden404; public opt-in only. Cursors are not authority. |
| Permission checks: MemoryV4 | _require_permission, AuthContext.has | Host operation grants necessary, insufficient for data action | Shared domain rechecks mapped memory permissions; admin never skips scope/invariants. No implicit admin resolver. |
| Roles/autonomous candidates: MemoryV4 | _authorize_create, RecordCreate; create-working exactly active/working | No frozen memory truth model | Preserve active/working defaults and strict model fields. Canonical requires explicit promotion grant. Canonical portable format is not role authority. |
| Write policy: MemoryV4 | _authorize_record_edit/_supersede; patch policy owner checks | No Kernel record-policy equivalent | Extract existing checks, not replace by capability admission; immutable/canonical patch still denied even admin. |
| Promotion/lifecycle: MemoryV4 | promote/transition routes + Store atomic guards | No frozen generic lifecycle equivalent for records | Memory lifecycle != service lifecycle. Preserve permission, reason, version, exact restoration, terminal superseded state; no public promotion capability needed for minimum slice. |
| Supersession/history: MemoryV4 | supersede_record_idempotent, source/replacement links/audit | No equivalent | Preserve atomic source closure/replacement attribution and history; canonical import cannot silently revise/promote. |

| Retrieval evidence: MemoryV4 | search_records_page actor + retrieval event | No equivalent | ACAP search invokes same domain, not Store or HTTP route shortcut; outages not empty success. |

| Store/schema/recovery: MemoryV4 operations | Store/SqliteStore/migrations/recovery | Foundation Data Authority/lifecycle declarations, not a new storage API | Extend existing port to methods domain actually uses; SQL/FTS below port. Runtime SQLite initialization at composition boundary only. Backup/migration distinct from canonical exchange. |
| Human rendering: UNIUI | existing UI ownership | Foundation optional UI metadata only | No new UI/integration; not part of slice. |
| Sessions/transient framework state: frameworks | ADR Tier2 exclusion | Host instance/scope lifecycle | Do not ingest sessions/secrets into durable memory or add Hermes provider integration. |

Authorized isolated ACAP is a new peer adapter deployment, explicitly reconciled with operational ADR container/sole-UNIFY deployment constraints by scoped Phase5.1 plan. It does not replace or bypass operational UNIFY, authorize a public memory port, or change application HTTP contracts. Native operator trust is explicit; no hostile-code isolation claim.

Negative acceptance obligations: forged actor/permissions/scope fields; absent map; denied Host operation; sibling/root escape; create-working→canonical; immutable/canonical edits; stale versions; missing key/reason; ambiguous replay; denied audit and retrieval evidence through both peer adapters. M10 remains provisional until M11 shared-domain execution.
