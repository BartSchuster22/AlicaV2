## Implemented contract and source

- CONTRACT-REVIEW-R1.md contains the exact approved EOF sealing paragraph, invalid/unsealed close disposition, explicit endpoint/version routing and knowledge/code semantics.
- `docs/g7/draft/contracts.schema.json` and its generator `tools/g7-contract-model.py` add only `adminRequestV2` and `adminResponseV2` and their root-union alternatives. Every original definition, including both v1 admin definitions, is preserved. The v2 request is an exact deep clone except version. V2 response requires all original fields, forbids extras and permits only zero/null known absence, positive/digest known selection, or null/null NEEDS_OPERATOR/CLEANUP_UNCERTAIN unknown. No limit file change.
- `tools/g7-supervisor.py` listens on both `supervision/admin.sock` and `supervision/admin-v2.sock`. Actual SO_PEERCRED UID checks and 0600/0700 modes apply to both. They share one custodian, incarnation, continuously held flock/fence, pending-operation slot and aggregate eight admitted connections. Each connection has one admission-based 30000 ms deadline, rechecked at socket events and after parsing before dispatch; bytes and EOF cannot renew it.
- No mutation dispatches before write EOF after exactly one complete frame. Invalid, incomplete, unsealed, trailing or wrong-version requests close without a response/effect. The server never negotiates versions or replays an operation. Disconnect after dispatch does not cancel the shared pending operation.
- V2 unknown selection reports the constrained null/null envelope without reading potentially uncertain storage in the custodian. While successor validation is pending, the prior snapshot is retained only as an internal comparison binding, not emitted as a fresh v2 selection certificate. Failure still discards it and latches uncertainty. V1 remains v1-only and closes when selection is unknown. A known durable selection can still accompany NEEDS_OPERATOR when only lifecycle cleanup is uncertain.
- CLEANUP_UNCERTAIN in the unknown envelope means safe lifecycle/selection disposition is uncertified, not proof a particular disposer failed. Neither unknown nor transport failure authorizes retry, restart, custody release or reconciliation. No expectedSequence/stale digest/zero placeholder is substituted for unknown. Late exit, readable accepted bytes and repeated requests cannot revoke a latched fence.
- `tools/g7-admin.mjs` is a one-attempt host client API: `adminRequest(root, version, request)`. It requires explicit version, validates that request, half-closes write, strictly parses a bounded single response through EOF, validates exact response version/requestId/incarnation, and rejects transport/protocol failure with in-process `outcome: UNKNOWN_OUTCOME`. This is not a new wire field. No fallback or replay.
- `tools/check-boundaries.mjs` permits the existing pinned Ajv target for the exact new host importer only. `tests/foundation/foundation.test.mjs` verifies that narrow exception and rejects other importers/targets. No Kernel/G6 source/API, new dependency or installation is involved.
