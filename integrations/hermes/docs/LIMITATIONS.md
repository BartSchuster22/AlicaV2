## Scope

One immutable fixture task, one native tool, one fixed model configuration and
single-flight request-owned process. No general conversational product, persistent
session/resume, complete plugin integration, multi-harness orchestration, service
integration or production hostile-code sandbox. Catalog addition is EXPERIMENTAL.

## Runtime and evidence limits

- Public30s is parent-enforced; child119/outer120 are separate ceilings, not a
  propagated remaining public deadline. Local kill is not remote cancellation.
- No provider token/generation/billing ceiling. Durable reservation count is not
  provider billing evidence. Original one-shot is finished, consumed2of3; remaining1
  must never be interpreted as a fresh permission.
- Parent/cleanup-owner death, arbitrary filesystem cleanup failure, escaped
  process sessions and secure memory erasure are not certified.
- Process native failures are normalized to UNAVAILABLE, not raw Python errors.
  Detailed model/tool classification is not exposed as a stable public API.
- Current native binding checks the exact pinned checkout and rejects a wrong
  revision before isolation/import. This is a trusted Git checkout check, not
  remote runtime attestation or hostile-owner protection. The explicit negative
  is test_final_native.FinalNative.test_wrong_checkout_rejected_before_isolation.
- MOCK reproduction reuses historical live evidence. MOCK model replies never
  count as additional H12 proof. Existing regression counts include imported
  topology executions more than once, not that many distinct cases.
