## Controls that must be proved, not assumed

- `run_agent.py` at the pin defaults max_iterations to sys.maxsize; current library guide's table says 500. Always pass a finite explicit bound.
- `plugins_discovery.py:232–281`: explicit disabled set wins, but bundled backend plugins auto-load before the general enabled-list check. An empty enabled list alone does not establish the approved profile. Inventory all discovered categories and deny unwanted bundled keys; inspect observed loaded state before a run.
- `agent/agent_init.py:1106+` calls plugin discovery before selecting tools. `skip_memory` does not disable the built-in memory tool if that toolset is explicitly selected. External context-engine selection is separate. Fail closed on any unexpected schema/handler/provider.
- `skip_context_files=True`, `load_soul_identity=False`, `skip_memory=True`, `skip_background_review=True`, no checkpoints/trajectories, no fallback chain or credential pool, dedicated HOME/HERMES_HOME/cwd and an allowlisted environment are necessary controls, not yet tested adapter enforcement.
- Inference network is the sole required model-facing network exception. No live call until endpoint/model, safe credential reference, request/token/time and spend ceilings are approved. Never expose credential values in evidence.
- Baseline 88 upstream tests are regression evidence only. No claim yet for H9/H12/H14 or production hostile-plugin containment.
