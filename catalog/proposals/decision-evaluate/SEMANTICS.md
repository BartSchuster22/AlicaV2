## Observable contract

acap://alica.io/decision/evaluate@1 maps explicitly to io.alica.decision.evaluate 1.0.0. One unary evaluate, idempotency=none. A Document is the closed envelope {"json":"<canonical frozen-ACAP JSON object>"}. Frozen ACAP's schema vocabulary requires closed objects and does not permit open dictionaries or recursive schemas; this Decision-only envelope preserves arbitrary structured state without changing ACAP. encodeDocument/decodeDocument enforce canonical bytes, reject duplicate keys through the frozen parser, and validate nested decimal markers. Plain text is encoded from {"text":"..."}; the json envelope itself is not forwarded to the provider. Input state is a shared Document; questions is a nonempty ordered array of unique names and kinds boolean/choice/score. Instructions and descriptions are Documents; no dependence on any provider's field vocabulary. Model is optional and resolved by provider configuration; returned model is resolved identity. Provider selection is visible host configuration, NOT request routing/authority. Unknown request/conditional fields are rejected. No hidden thresholds or reasoning loops.

Boolean returns probability of yes/true, never a thresholded Boolean. Optional true/false criteria describe those meanings. Choice accepts unique named options; result selects one maximum-probability candidate (ties permitted), includes every exact candidate once and provider-reported confidence. Score accepts unique level IDs and distinct canonical numeric values plus descriptions; result preserves exact ordered legend, expected score, confidence and every level probability. An adapter incapable of representing a generic level/rubric rejects explicitly, never rewrites the rubric. Names/kinds correspond exactly by identity (response ordering is not normative). Extra/missing/duplicate answers or candidates fail CONTRACT_MISMATCH. Meaningful usage inputTokens/outputTokens are nonnegative safe integers. No price or calibration promise.

## Frozen ACAP numeric boundary

DecisionDecimal is a canonical signed base10 string: 0 or -?[1-9][0-9]*, optionally fractional suffix ending in a nonzero digit; values between -1 and1 use canonical leading zero. No +, exponent, redundant leading/trailing zero, negative zero, whitespace, NaN or infinity. Maximum36 digits total and18 fractional places, maximum string length38. Values outside bounds fail, never round. Probability/confidence must be [0,1]; expected score lies within explicit rubric extrema. Distribution totals have absolute tolerance 0.000001 from1. Expected-score weighted-sum consistency has absolute tolerance0.000001 in score units; exact BigInt products are compared before division. Returned decimals are never renormalized or silently rounded.

Within state/instructions/criteria/rubric descriptions, safe integer JSON numbers remain integers, and literal strings remain strings. Fractional or larger exact numeric data uses reserved singleton {"$decisionDecimal":"0.125"}. That property is reserved: it cannot coexist with other properties or represent an ordinary object property. Literal domain objects needing this reserved key must be represented differently by the caller; there is no guessing. The document root must be an ordinary object, not a decimal marker. Nested arrays, null, booleans, strings and ordinary objects are supported. NaN/infinity/non-safe-integer bare numbers rejected. Fractional data must never be converted through Number.

Limits:32 questions,32 candidates/levels per question; IDs/names/model/provider match [A-Za-z0-9][A-Za-z0-9_.-]{0,127}. Whole request and response each <=65536 canonical UTF8 bytes, <=4096 structured nodes, depth<=16, cumulative textual content+keys<=32768 bytes. The bounded ACAP descriptor handles structural fields; semantic validators are mandatory for discriminated conditional fields, decimal syntax, exact correspondence and nested document limits. Provider contract imports no TypeSafe implementation.

Exact wire codec uses Node24 JSON.rawJSON after decimal validation. Numeric JSON ingestion uses JSON.parse reviver context.source, disregarding binary Number value and parsing the original lexical token including bounded exponents. Canonicalization removes lexical redundancy without rounding. Exponents larger than100 magnitude or resulting values beyond decimal bounds are rejected. This is Decision-boundary code, not a new ACAP numeric framework.

## Security and runtime

Public definePlugin/provide/require/clientEndpoint only; host owns caller scope, grants, revocation, lifetime and handle validity. Service validates/freeze-detaches request, invokes host-configured provider once, validates/freeze-detaches response. Disable switch rejects before provider invocation. Effective deadline is min(public remaining deadline,30s); cancellation is forwarded. No retry. Provider may continue work after timeout; no promise of remote cancellation/idempotency. No untrusted error message/body/cause retained; only finite safe ACAP codes. No state, keys, or provider bodies logged. Provider must honor the signal when technically possible.

Neutral reference picks first or last option deterministically with point distributions, fractional Boolean fixture, no external calls. This proves conformance and substitution only, not intelligence/calibration. Testkit evidence is SDK_TESTKIT_NOT_PRODUCTION and is not signed trust, production grants or Cell isolation. Real public Host/external acceptance remains a later explicit slice. Live credential absence does not change fixture classification.
